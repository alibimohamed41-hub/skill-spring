# SkillSpring ✦

موقع عربي تفاعلي يساعدك على اكتشاف المهارات وتنظيم خطة تعلّمك ومتابعة التقدّم. التصميم متجاوب مع الهاتف والحاسوب، ويمكن نشره مجانًا على GitHub Pages.

## المزايا
- واجهة عربية من اليمين إلى اليسار (RTL) وتصميم عصري.
- ستة مسارات تعلّم ضمن التقنية والإبداع ومهارات الحياة.
- بحث مباشر وتصنيف المسارات.
- إضافة المهارات إلى خطة شخصية، مع وضع علامة على المهام المكتملة وحذفها.
- إحصائيات للتقدّم.
- مؤقّت تركيز مدته 25 دقيقة.
- تغيير بين المظهر الداكن والفاتح.
- اقتباسات تحفيزية.
- حفظ الخطة والتفضيلات محليًا في المتصفح باستخدام `localStorage`.

## الملفات
- `index.html` — هيكل الموقع.
- `style.css` — التصميم والتجاوب مع الشاشات المختلفة.
- `script.js` — التفاعلات والحفظ المحلي.
- `README.md` — هذا الدليل.

## تشغيل الموقع محليًا
افتح `index.html` في متصفح حديث. لا يحتاج الموقع إلى خادم أو خطوة بناء.

## النشر على GitHub Pages
1. سجّل الدخول إلى GitHub.
2. أنشئ مستودعًا جديدًا باسم `skillspring` (أو اسم آخر تختاره).
3. ارفع الملفات الأربعة إلى **جذر المستودع**، بحيث يكون `index.html` ظاهرًا مباشرةً عند فتح تبويب **Code**.
4. افتح **Settings → Pages**.
5. في **Build and deployment**، اختر **Deploy from a branch**.
6. اختر الفرع `main` والمجلد `/(root)`، ثم اضغط **Save**.
7. افتح **Actions** وانتظر انتهاء عملية النشر بنجاح، ثم ارجع إلى **Settings → Pages** لعرض رابط الموقع.

إذا كان اسم حساب GitHub هو `alibimohamed41-hub` واسم المستودع `skillspring`، فالرابط المتوقع بعد نجاح النشر هو:

`https://alibimohamed41-hub.github.io/skillspring/`

قد يستغرق النشر بضع دقائق. الرابط أعلاه متوقع وليس دليلًا على أن النشر اكتمل حتى تفعّل Pages بنجاح.

## ملاحظات
- الخطة محفوظة في المتصفح الحالي فقط؛ لا يوجد حساب مستخدم أو مزامنة بين الأجهزة.
- مؤقّت التركيز يعمل ما دامت صفحة الموقع مفتوحة، ولا يحتاج إلى صلاحيات خاصة.
- الخط الخارجي من Google Fonts يحتاج إلى اتصال بالإنترنت، وسيستخدم المتصفح خطًا بديلًا إذا تعذّر تحميله.
- المشروع واجهة أمامية مستقلة ولا يرسل بياناتك إلى خادم.
